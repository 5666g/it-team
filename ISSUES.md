### Issue #1: [Task 1] Заполнение страницы участников команды
* **Заголовок:** `feat: Наполнение страницы участников команды (pages/team.html)`
* **Исполнитель:** Студент 1
* **Цель:** Представить ключевых участников команды разработчиков, их специализации и профессиональные роли.
* **Файл для изменения:** `pages/team.html`
* **Рекомендуемая ветка:** `feature/team-members`
* **Пример коммита:** `feat: добавить карточки участников команды`

#### Описание задачи:
Необходимо открыть файл `pages/team.html` и заменить блок-заглушку (`.stub-box`) на красивые карточки участников команды (минимум 3 участника). В качестве образца используйте разметку карточек из `pages/template.html` или раскомментируйте готовый пример в файле.

#### Список требований:
1. Заменить блок `<div class="stub-box">` на секцию с классом `.content-section`.
2. Добавить минимум 3 карточки участников с классом `.card`.
3. Для каждого участника указать:
   - Имя и фамилию (в заголовке карточки `<h3>`).
   - Иконку-эмодзи и бейдж роли (например, Team Lead, Frontend, Backend, DevOps, QA).
   - Краткое описание обязанностей/опыта (в блоке `.card-body`).
   - Тег специализации (в блоке `.card-footer`).
4. Не удалять шапку (`<header>`), подвал (`<footer>`) и меню навигации.
5. Не вносить изменений в другие файлы репозитория.

#### Критерии завершения (Definition of Done):
- [ ] Файл `pages/team.html` успешно открывается в браузере и отображает тёмную тему без искажений.
- [ ] Блок с заглушкой удалён, на его месте отображаются 3 или более карточки участников.
- [ ] Меню навигации работает, ссылки на главную и соседние страницы не сломаны.
- [ ] Изменения зафиксированы в ветке `feature/team-members` с понятным сообщением коммита.
- [ ] Открыт Pull Request в репозиторий преподавателя с выбором `base: main`.
